# Vela Hardware — Flagship E-Commerce Store

A modern, high-performance digital flagship store designed and developed for precision-engineered **Laptops**, **Smartphones**, and **Handsfree / Acoustic Audio**.

Built with React 19, TypeScript, Tailwind CSS, and Vite.

---

## 🚀 Key Features

### 1. Three Core Hardware Departments
- **Laptops**: High-performance workstations, thin-and-light ultrabooks, and creator reference laptops with detailed specifications (CPU, GPU, RAM, Mini-LED/OLED display, battery hours, ports, weight).
- **Smartphones**: Flagships with 1-inch physical camera sensors, zero-crease titanium foldables, and compact everyday flagships with 120Hz LTPO AMOLED displays.
- **Handsfree & Audio**: True wireless earbuds with 48dB hybrid Active Noise Cancellation (ANC), planar magnetic over-ear wireless studio headphones, sports neckbands, and zero-latency Type-C audiophile earsets.

### 2. Interactive Hardware & Acoustic Lab
- **Handsfree ANC Chamber**: Real-time simulated frequency analyzer comparing passive seal, ambient transparency, and full 48dB hybrid ANC across aircraft cabin, subway, and cafe soundscapes.
- **Phone 120Hz & Optics Simulator**: Kinetic fluidity comparison comparing 60Hz vs 120Hz adaptive refresh rates, along with 1-inch sensor periscope zoom testing (1x, 3.5x, 10x).
- **Laptop Vapor Chamber**: Interactive thermal & workload profile benchmark (Turbo 175W, Studio Balanced 115W, and Autonomous Eco).

### 3. Shopping Experience & Checkout
- **Interactive Device Comparison Matrix**: Side-by-side spec comparison table for selected hardware models.
- **Product Detail Modal (PDP)**: Finish/color swatches, comprehensive technical specification table, verified customer reviews, and quantity selector.
- **Shopping Bag & Express Checkout**:
  - Live subtotal and discount calculations.
  - Promo code support (`VELA10` for 10% off, `FLAGSHIP` for 15% off).
  - Free express delivery indicator.
  - Supports both **Credit/Debit Card** and **Cash on Delivery (COD)** with customer verification.
  - Realistic post-order receipt screen with tracking ID and shipping breakdown.

## 💻 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ahadkazmi69-cmd/ecommerce-store.git
cd ecommerce-store
```

2. Install dependencies:
```bash
npm install
```

3. Start the local development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
